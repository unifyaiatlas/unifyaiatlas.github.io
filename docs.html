Databricks Lakebase Metastore Technical Specification

Instead of relying on an external disconnected relational database (e.g. Postgres or RDS) for metadata, Unify AI uses Databricks Lakebase: a high-performance active control-plane schema housed directly inside Unity Catalog (system.unify_lakebase).

💡 Why Databricks Lakebase as Metastore?
All configuration, canonical schemas, match rules, survivorship matrices, and data quality thresholds are stored as Delta tables with ACID guarantees, time-travel history (VERSION AS OF), automatic column-level lineage, and zero-latency Spark/SQL engine access.
